# 验证范围

## 自动验证

核心 JVM 测试集中在：校准反解与失效、数据新鲜度、垂直精度/高度基准、滤波输入、爬升噪声与中断、CSV/GPX 语义。没有为普通 getter、枚举标签或转发方法补测试。

Android 测试覆盖 Room 恢复与级联删除、跨分页导出和图表极值保留，以及无传感器状态与仪表记录入口的可达性。UI 截图使用测试专用固定数据，不会进入发布应用。

## 实机验收

模拟器和测试数据不能证明真实传感器精度。发布前在带气压计和无气压计设备上验证：

- 首次拒绝定位、仅近似定位、永久拒绝后去设置授权，界面均给出可操作状态。
- GNSS 冷启动、室内失锁、关闭定位，以及 Android 14+ 海平面转换回退。
- 已知标高校准、负海拔、相对归零、电梯上下行，气压噪声不会持续累计爬升。
- 前台开启行程后锁屏 30 分钟；通知结束、切回应用、旋转屏幕，采样不重复且零点不变。
- 强制停止进程后再打开：已提交的数据可见，行程为中断，不自动续录。
- 厂商省电策略（尤其 vivo / Samsung）可能额外停止服务；检查长时间锁屏行为。
- 1.5× / 2× 字号、窄屏、横屏、浅深主题、TalkBack；关键操作可滚动到达。
- CSV/GPX 文件经其他软件打开，位置缺失时不出现 `(0,0)` 伪轨迹。
